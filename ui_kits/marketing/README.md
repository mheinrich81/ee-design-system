# Marketing UI kit — Elevate Execution

Static marketing recreation. **Speculative** — there's no real site to mirror; this is built from the brand brief.

## Surfaces in this kit

| File | What's in it |
|---|---|
| `index.html` | Stitches the whole page together |
| `TopNav.jsx` | Sticky frosted nav with wordmark + links + CTA |
| `Hero.jsx` | Display headline, subhead, dual CTA, ridgeline at bottom |
| `FeatureGrid.jsx` | 3-up feature blocks with Lucide icons |
| `MetricStrip.jsx` | Single alpenglow-gradient KPI band (one per page max) |
| `LogoWall.jsx` | Customer placeholder strip |
| `CTABanner.jsx` | Closing call-to-action card |
| `Footer.jsx` | Three-column footer with ridgeline behind |

## Design rules followed

- **Snow** background, never `#FFFFFF` for the page
- One alpenglow-gradient moment (the metric strip) — and nowhere else
- Bricolage Grotesque only on display + headings; Geist for everything else
- Lucide icons at 1.5px stroke, currentColor only
- Sentence case across the whole page; no exclamation marks
