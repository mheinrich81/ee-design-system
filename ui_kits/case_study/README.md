# Case study UI kit — Elevate Execution

The second key surface for a consultancy: a detailed case study page. Marketing pulls people in; case studies close them.

## Surfaces in this kit

| File | What's in it |
|---|---|
| `index.html` | Stitches the page together — uses marketing TopNav + Footer |
| `CaseHero.jsx` | Client name, summary, scope card, primary outcome |
| `SituationSection.jsx` | "What we walked into" — narrative + a single pull stat |
| `ApproachTimeline.jsx` | Phased engagement timeline (week-by-week) |
| `PullQuote.jsx` | Client testimonial, full-width, restrained |
| `OutcomesGrid.jsx` | 4-up outcome metrics in cards |
| `RelatedCases.jsx` | Two related case studies + CTA |
| `styles.css` | Local additions — imports marketing styles for nav/footer/buttons |

## Design rules followed

- Same Bricolage Grotesque display, Geist body, JetBrains Mono for metrics
- One alpenglow moment per page (the outcome hero metric)
- Snow page · no pure white · no gradient elsewhere
- Lucide icons, 1.5px stroke
- Tone: slightly more direct than marketing — case studies should sound like an after-action report, not a sales pitch

## What this isn't

A working CMS. The content is a single sample case study (Foothills Labs, fictional).
